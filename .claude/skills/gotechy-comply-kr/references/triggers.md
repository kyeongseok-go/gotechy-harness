# 트리거 질문: 어떤 기능이 어떤 법을 부르나

기능 목록에서 해당 법과 조문을 고를 때 연다. 질문마다 "예, 아니오, 모름" 중 하나로 답하고, "예"와 "모름"은 요구사항 표에 행을 만든다. "아니오"도 이유를 한 줄 남긴다(나중에 기능이 바뀌면 다시 묻기 위해서다).

조문 요지와 원문 링크는 `laws.md`에 있다. 이 표는 출발점이고, 원문을 열어 현행 조문을 확인하기 전에는 요구사항으로 확정하지 않는다.

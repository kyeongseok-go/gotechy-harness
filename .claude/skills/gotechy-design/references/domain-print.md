# 인쇄물 분야: 현수막, 포스터, 분할 출력 본

언제 여는 파일인지: 결과물이 종이나 천에 실제 크기로 출력될 때(현수막, 무대 배경, 포스터, 집 프린터로 나눠 뽑아 붙이는 글자 본과 이름 카드, 인쇄소에 넘길 파일). 웹 화면의 사용자 흐름 게이트는 여기에 걸지 않는다. 각 절의 원천은 `bar.md`의 인쇄물 원천 표에 있다.

## 1. 시작 조건

다음 네 가지를 먼저 묻거나, 모르면 가정을 적고 진행한다.

| 항목 | 예 | 왜 |
|---|---|---|
| 완성 크기(mm) | 3500 × 2300 | 모든 계산의 기준 |
| 출력 수단 | 인쇄소 실사 출력, 집 프린터 A4 | 해상도, 여백, 분할 여부가 갈린다 |
| 보는 거리 | 무대 뒤 5~15m | 글자 높이와 필요한 해상도가 정해진다 |
| 수량과 붙이는 방법 | 이름 카드 100장, 양면테이프 | 장 수, 재료, 조립 순서 |

## 2. 실제 크기 시안

- HTML이나 SVG에서 1px을 1mm로 두고 그린다. 3500 × 2300mm면 캔버스도 3500 × 2300이다. 숫자를 바로 읽을 수 있어 실수가 준다.
- 헤드리스 브라우저로 렌더링해 확인한다. 큰 화면을 한 번에 높은 배율로 찍으면 검은 조각이 생길 수 있어, 가로 띠로 나눠 찍고 이어 붙인다.
- 글자 높이는 보는 거리로 정한다. 멀리서 읽을 제목은 크게, 이름처럼 가까이 와서 볼 글자는 작아도 된다. 정한 글자 높이를 mm로 시안에 적는다.
- 선 굵기는 mm로 직접 준다. 화면 픽셀 기준 옵션(`vector-effect: non-scaling-stroke`)은 출력 본의 선을 너무 가늘게 만든다.

## 3. 출력 해상도 계산

- 식: 출력 dpi = 픽셀 수 ÷ (출력 mm ÷ 25.4). 예: 10500px을 3500mm로 뽑으면 10500 ÷ 137.8 = 약 76dpi.
- 판단은 보는 거리와 고른 인쇄소의 기준으로 한다. 멀리서 보는 현수막은 300dpi가 필요 없다. HP 표는 6m(20피트) 넘게 떨어져 보는 바깥 현수막에 50~100PPI, 1.5~3m 거리 포스터에 100~150PPI를 든다.
- 인쇄소 기준은 크게 다르다(2026-11-08 확인): 비즈하우스는 현수막 최소 120dpi, 와우프레스는 1/10 크기 작업에 700dpi(실제 크기 70dpi), 광고천하는 실제 크기 150ppi를 안내한다. 그래서 계산한 값(예: 76dpi)을 고른 인쇄소의 최소값과 비교해 답에 적고, 모자라면 픽셀을 늘리거나 그 인쇄소에 확인한다.
- 같은 가이드들이 함께 요구하는 것: 색 모드(비즈하우스, 와우프레스는 CMYK), 글자 윤곽선 처리, 그라데이션과 투명 효과 병합, 재단 여유(레드프린팅은 사방 2mm)와 안전 영역(재단선에서 10mm 안쪽에 글자와 로고).

## 4. 집 프린터로 나눠 출력하기

- 인쇄 가능 영역 = 용지 크기 − 프린터 여백. 일반 프린터는 종이 가장자리까지 찍지 못한다(예: Brother A4 레이저는 사방 4.2mm, 크로미움 계열 인쇄 대화상자의 "최소" 여백은 약 6.35mm). 여백을 모르면 사방 5mm(하네스 기본값)로 잡고 그 가정을 적는다.
- 큰 본은 여러 장으로 나누고, 이웃 장끼리 10~20mm 겹침 띠(풀칠 자리)를 둔다. 겹침 없이 맞대면 이음매가 벌어진다.
- 장마다 맞춤 표시(십자 표시나 맞춤 점선), 장 번호(예: G-1, G-2), 조립 순서를 넣는다. PDF 하나를 크게 나눠 뽑을 때는 Acrobat의 포스터 출력(겹침, 재단 표시, 라벨)을 써도 된다.
- 첫 장에 기준 자(예: 50mm 눈금)를 넣는다. 출력 뒤 자로 재서 배율이 맞는지 확인한다.
- 출력 설정은 "실제 크기(100%)"다. "용지에 맞춤"은 배율을 바꿔 조각이 맞지 않는다. 안내문 첫 줄에 적는다.
- 가로, 세로 페이지가 섞이면 CSS 이름 있는 페이지로 나눈다: `@page land { size: A4 landscape }`와 요소의 `page: land`.

## 5. 개수와 장 수 계산

- 한 장당 개수 = ⌊인쇄 가능 폭 ÷ 카드 폭⌋ × ⌊인쇄 가능 높이 ÷ 카드 높이⌋. 카드를 90도 돌린 경우와 용지를 가로로 놓은 경우도 계산해 큰 값을 쓴다.
- 총 장수 = ⌈전체 개수 ÷ 한 장당 개수⌉.
- 예(여백 사방 5mm): 140 × 60mm 카드는 A4에 6개, 100개면 17장. 190 × 90mm 카드는 A4 세로에 3개(34장), A3 가로에 6개(17장).
- 글자 높이는 카드 높이의 약 60%를 시작점으로 하고, 4글자 이름은 글자를 줄여 넣는다.

## 6. 출력 전 자동 검사

- 잘림 검사: 요소마다 경계 상자(SVG `getBBox()`, HTML `getBoundingClientRect()`)를 구해 인쇄 가능 영역과 비교한다. 넘치면 실패로 멈추고 PDF를 만들지 않는다. `getBBox()`는 기본으로 선 굵기를 빼고 변환 전 좌표를 주므로 `{stroke: true}`를 주고 페이지 좌표로 바꿔 비교한다. `getBoundingClientRect()`는 화면 기준이라 스크롤 값을 더한다.
- 페이지마다 렌더링: 모든 페이지를 이미지로 뽑아 하나씩 본다. 거의 흰 픽셀뿐인 페이지는 빈 페이지 오류로 본다(코드의 숫자 변환 실수로 빈 페이지가 나온 실제 사례가 있다).
- 사람 확인은 그 다음이다. 자동 검사가 통과해도 첫 장은 실제로 출력해 자로 잰다.

## 7. 파일 무게와 넘기기

- 질감 필터와 큰 그라데이션은 PDF를 수십 MB로 키운다. 페이지를 JPEG로 래스터화한 뒤 다시 PDF로 묶으면 몇 MB로 준다(글자 선명도는 확인한다).
- 인쇄소용 파일과 집 출력용 파일을 따로 낸다. 실명 명단이 든 파일은 공개 링크에 올리지 않는다.

## 흔한 실패와 고치는 법

| 실패 | 고치는 법 |
|---|---|
| 인쇄물 요청에 사용자 흐름부터 만들자고 멈춘다 | 분야를 먼저 판별하고 1절의 시작 조건만 확인한다 |
| 무조건 300dpi로 다시 만들라고 한다 | 3절 식으로 계산하고 보는 거리와 인쇄소 기준으로 판단한다 |
| 종이 전체 크기로 개수를 계산한다 | 여백을 뺀 인쇄 가능 영역으로 계산한다 |
| 겹침 없이 나눠 출력한다 | 10~20mm 겹침 띠와 맞춤 표시를 넣는다 |
| 마지막 장의 본이 종이 밖으로 잘린다 | 6절의 경계 상자 검사를 출력 전에 돌린다 |
| "용지에 맞춤"으로 출력해 조각이 맞지 않는다 | 실제 크기(100%)로 출력하고 기준 자로 잰다 |

# /gotechy-launch — 런치 & 마케팅

## 절차

1. **런치 체크리스트 (docs/BRAND.md)** — 랜딩의 3초 규칙, 데모 GIF, README 채용 담당자 시선 점검. 미달 항목은 목록으로 보고하고 수정 여부를 확인한다.
2. **SEO/GEO 감사** — 대상 페이지에 대해:
   - 제목·description·OG 태그·JSON-LD 구조화 데이터
   - 첫 문단 결론 구조 (AI 답변 엔진 인용 최적화 — GEO/AEO)
   - 시맨틱 헤딩, 이미지 alt, 내부 링크
3. **콘텐츠 3종 세트 생성**:
   - **블로그**: `/gotekie-blog-writer`로 런치 글 (유형: 리뷰 또는 튜토리얼). Surprises & Discoveries의 삽질 기록을 재료로 쓴다.
   - **쓰레드**: 블로그를 5-7개 포스트 분량으로 변환 (첫 포스트 = 훅 + 결과 스크린샷, 마지막 = 블로그 링크). `Output/threads/` 형식.
   - **유튜브**: 스크립트 아웃라인 (인트로 훅 15초 → 데모 → 삽질 포인트 → 마무리 CTA). `Output/youtube/` 형식.
4. **저장** — 산출물은 노션 호환 frontmatter를 포함해 저장하고, Gotechy-Wiki `Output/` 경로로의 ingest를 안내한다.

## 완료 기준

- 체크리스트 판정 + 3종 콘텐츠 초안 생성. 발행(외부 게시)은 하지 않는다 — 초안까지가 이 스킬의 범위이고, 발행은 사용자가 한다.

# DESIGN.md — 디자인 시스템과 철학

> 첫인상 기준의 진실의 원천. 다른 문서에서 "3초 규칙"을 인용할 때는 이 문서를 링크한다.
> 프로젝트별 토큰 **값**의 결정은 위저드 산출물 `60-style-guide`(성격 축→레퍼런스→역할 5색, `docs/WIZARD.md`)에서 하고, 이 문서는 그 결정이 지켜야 할 상위 규범(대비·수치 시스템·anti-slop)이다.

## 기본 방향 (범용 템플릿 규칙)

- **제품 UI 기본값은 라이트 테마 + 뉴트럴 그레이 스케일**이다. 1순위 사용자(부모님+AI 초심자, `PRODUCT_SENSE.md`)에게 다크+네온은 가독성 최악 조합이다.
- 다크 기본 적용은 개발자 도구·미디어성 제품 등 **근거를 스펙에 기록했을 때만**.
- 아래 "고텍이 브랜드 팔레트"는 **고텍이 포트폴리오·마케팅·기술 데모용 기본값**이며 프로젝트별 교체 가능하다.

## 토큰 구조 — 2층 (원시 → 시맨틱)

컴포넌트는 **시맨틱 토큰만** 사용한다. 원시 팔레트를 직접 참조하는 코드는 재작업 대상.

```css
/* 1층: 원시 팔레트 (예시 — 고텍이 브랜드) */
--palette-cyan-400: #00E5FF;   /* 다크 배경 전용 */
--palette-cyan-700: #0E7490;   /* 라이트 배경용 (대비 4.5:1+) */
--palette-mint-400: #00FF88;   /* 다크 전용 */  --palette-mint-700: #047857;
--palette-coral-400: #FF6B9D;  /* 다크 전용 */  --palette-coral-700: #BE185D;
--palette-violet-500: #7C3AED; --palette-gray-50~900: (뉴트럴 스케일);

/* 2층: 시맨틱 토큰 (컴포넌트가 쓰는 것) */
--color-bg-base / --color-bg-raised / --color-text-primary / --color-text-muted
--color-accent / --color-border / --color-focus
--color-danger / --color-warning / --color-success
```

**대비 규칙**: 텍스트·아이콘으로 쓰이는 모든 색은 배경 대비 **4.5:1 이상**을 토큰 정의 시점에 검증하고 주석으로 대비값을 남긴다. 네온 계열(#00E5FF, #00FF88, #FF6B9D)은 **다크 배경 전용** — 라이트에서는 -700 단계를 쓴다.

**테마 전환**: `prefers-color-scheme` 기본 + `[data-theme]` 명시 오버라이드. `body`에 배경색 명시(투명 금지). 다크 본문 텍스트는 순수 `#FFF` 금지 — `--color-text-primary`(예: #E7E9F0).

## 수치 시스템 (에이전트가 지어내지 못하게)

| 항목 | 규칙 |
|---|---|
| 간격 | 4px 배수만: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| radius | 2단계만 — 컨트롤 8px, 카드·모달 12px. **세 번째 값 발견 시 재작업** |
| 타이포 스케일 | 12 / 14 / 16 / 20 / 24 / 32 / 40px |
| 본문 | 16px, line-height 1.7. 최소 크기 14px |
| 헤딩 | line-height 1.3, letter-spacing -0.02em, `text-wrap: balance` |
| 한국어 줄바꿈 | `word-break: keep-all`은 헤딩·짧은 라벨에만 (본문 장문 적용 금지) |
| 터치 타깃 | 최소 44×44px |
| 포커스 | 모든 인터랙티브 요소에 `:focus-visible` 커스텀 링 2px(`--color-focus`), 마우스 클릭 시 미표시 |

**타이포그래피**: 한글 Pretendard(헤딩 700-800, 본문 400), 영문 헤딩 Space Grotesk, 코드 JetBrains Mono. 폴백 스택 필수.

## 상태 매트릭스 (상태 3종은 절반이다)

| 상태 | 규칙 |
|---|---|
| 로딩 | 300ms 미만 응답엔 로딩 UI 금지. 300ms+는 스켈레톤(스피너 아님). 10s 초과 시 타임아웃+재시도 |
| 빈 상태 | 두 종류 구분 — 최초 사용(온보딩 CTA) vs 필터 결과 없음(필터 해제 링크) |
| 에러 | 재시도 가능 / 권한 부족(401 vs 403) / 오프라인을 구분, 각각 다음 행동 1개 제시 |
| 부분 실패 | 성공분은 렌더링, 실패분만 인라인 재시도 |
| 낙관적 업데이트 | 실패 시 롤백 + 알림 경로 명시 |

## Anti-Slop 체크리스트 (측정형 — 하나라도 걸리면 재작업)

- [ ] 그라데이션은 페이지당 1곳 이하, 사용 시 목적을 코드 주석으로
- [ ] radius 값 3종 이상 발견 시 실패
- [ ] 이모지를 UI 아이콘으로 사용 0개 (아이콘 라이브러리 1종 통일)
- [ ] `backdrop-blur`는 오버레이에만
- [ ] gradient text 금지, 카드 전체 `hover:scale` 금지
- [ ] 전 섹션 중앙정렬 반복 금지, "아이콘+제목+두 줄" 3열 feature grid 무근거 사용 금지
- [ ] 다크 본문 `#FFF` 금지 (halation)
- [ ] placeholder 스톡 이미지·가짜 지표·가짜 후기 금지
- [ ] "혁신적인", "강력한" 등 빈 수식어 금지

## 경험 원칙

1. **3초 규칙** — 첫 화면에서 "이게 뭐고 뭘 하면 되는지" 3초 안에 파악.
2. 상태 매트릭스 준수 (위 표).
3. 모션은 의미가 있을 때만 — 200ms 이하, `prefers-reduced-motion` 존중.
4. 접근성 게이트 — axe 자동 검사 위반 0건, 키보드만으로 핵심 여정 완주 가능(Tab 순서 = 시각 순서). 검사 항목은 `QUALITY_BAR.md`가 집행.

# 0002. 배포: 파일이 정본, AGENTS.md가 라우터, apm이 설치기

- 상태: 승인됨
- 날짜: 2026-10-14 (결정 D5, 2026-10-13)
- 관련: [설계 문서 12절 D5](../design-docs/2026-10-13-expert-library-v0.md), [1a ExecPlan M3](../exec-plans/completed/2026-10-13-harness-v2-phase1.md), [리서치 15절](../references/research/expert-library-research-2026-10.md)

## 맥락

전문가 라이브러리(스킬, 팩, 규칙)를 Claude Code, Codex 등 여러 도구와 여러 컴퓨터에 같은 버전으로 깔아야 한다. 도구마다 스킬을 읽는 위치와 형식이 다르고, MCP로 스킬을 배포하는 표준(SEP-2640)은 확정됐지만 주요 도구가 아직 지원하지 않는다. 설치 결과가 바뀌었는지(변조, 드리프트) 기계로 확인할 수 있어야 한다.

## 검토한 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 파일 정본 + AGENTS.md 라우터 + apm 락 (선택) | 어느 도구든 파일은 읽는다. apm이 파일별 해시 락, `--frozen`, `audit --ci`를 준다(M0 확인) | apm이 0.x라 자체 버전도 고정해야 한다. 로컬 경로 설치는 락에 절대 경로가 들어간다 |
| B. MCP 서버로 스킬 배포 | 도구 하나로 실시간 갱신 | 주요 도구 미지원, 네트워크 의존 |
| C. 도구별 복사 스크립트 | 의존성 없음 | 해시 검증과 드리프트 감지를 직접 만들어야 한다 |

## 결정

A. 정본은 저장소의 파일(SKILL.md, AGENTS.md)이다. AGENTS.md는 백과사전이 아니라 "어디를 볼지"만 담은 짧은 지도다. 설치는 apm(`targets: [claude, agent-skills]`, git 원격의 커밋 SHA 고정, 2026-10-15에 태그에서 바꿈)으로 하고, apm은 교체 가능한 부품으로 둔다. MCP 배포는 주요 도구가 SEP-2640을 지원하면 어댑터로 더한다.

## 결과 (Consequences)

- 쉬워지는 것: 도구를 바꿔도 같은 파일을 읽는다. 변조는 `apm audit --ci`가 exit 1로 잡는다(M0 실험).
- 어려워지는 것: apm 0.x 변경을 따라가야 한다. `apm_modules/`에 원본 `.git`까지 복사되므로 `.gitignore`가 필요하다.
- 2026-10-15 갱신: `init`이 apm으로 설치한다(contract.md 10.7절). 고정은 태그 대신 **커밋 SHA**(train의 `packs.ref`)로 한다. 커밋은 바뀌지 않고, 태그를 따로 푸시하지 않아도 된다. git 의존성이라 락에 로컬 경로가 들어가지 않는다(로컬 경로 설치의 단점을 피함). apm은 관리하지 않는 같은 이름 폴더를 건너뛰고도 exit 0이라, init이 설치 전과 후에 직접 검사한다.

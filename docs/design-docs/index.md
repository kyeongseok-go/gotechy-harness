## 작성 규칙

- 파일명: `YYYY-MM-DD-주제-슬러그.md`
- 새 설계 문서를 만들면 반드시 이 색인에 추가한다.
- 구조에 대한 "결정"은 ADR(`../decisions/`)로, 결정에 이르는 "탐색·설계"는 여기로.
- doc-gardener가 **주 1회 + ship 게이트마다(스코프 한정)** 검증 상태를 갱신한다 (부채는 매일 소액 상환 — 분기 일괄은 몰아서 청소다).

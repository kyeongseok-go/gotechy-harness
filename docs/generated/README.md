# generated/ — 자동 생성 문서

> 이 폴더의 파일은 **도구가 만든다. 사람과 에이전트는 수동으로 편집하지 않는다.**
> 수동 편집하면 다음 재생성 때 덮어써진다 — 고칠 것이 있으면 생성 스크립트를 고친다.

## 대상 예시

| 파일 | 생성원 | 재생성 명령 |
|---|---|---|
| `db-schema.md` | DB 스키마 | (프로젝트별: 예 `npm run gen:schema-doc`) |
| `api-routes.md` | 라우트 정의 | (프로젝트별) |
| `dependency-graph.md` | import 분석 | (프로젝트별) |

## 규칙

- 코드에서 유도 가능한 문서는 손으로 유지하지 말고 여기로 옮겨 자동화한다.
- 각 파일 상단에 생성 시각·생성 명령을 주석으로 남긴다.
- CI에서 재생성 후 diff가 있으면 실패시키는 것을 권장 (문서 드리프트 방지).

## 작성 규칙

- 파일명: `기능-슬러그.md` (한 기능 한 파일). `/gotechy-spec`으로 생성.
- **제품·사이트 단위는 위저드 폴더**: `<슬러그>/00-brief.md … 60-style-guide.md` (`docs/WIZARD.md`). 색인에는 폴더를 한 행으로 등록.
- **확정 조건**: spec-reviewer 리뷰에서 🔴 0건 (🔴 기각 권한은 사용자에게만 있다).
- 출시 후 동작이 스펙과 달라지면 **스펙을 고친다** — 단, 확정 이후의 모든 변경은 스펙 하단 `변경 이력`에 날짜·내용·사유를 남기고, **Non-goals에서 항목을 빼는 변경(스코프 확대)은 사용자 승인 없이 금지**.
- 출시 2주 후 §3 성공 기준을 실제 측정해 결과를 스펙에 기록한다 (측정 결과가 다음 문제 정의를 고친다).

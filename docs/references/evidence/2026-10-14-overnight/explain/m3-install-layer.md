# 어디서든 같은 도구 묶음 (M3 설치 계층)

## 한 줄로

새 컴퓨터에서도 같은 버전의 도구를 깔고(`bin/gotechy`), 지금 상태가 맞는지 진단하고(`gotechy doctor`), 전역 설정을 바꾸되 언제든 원래대로 되돌릴 수 있게(`gotechy setup`) 했어요.

## train: 함께 검증한 버전 묶음

`train.yaml`에 도구마다 버전과 고정 등급을 적었어요. 기차 시간표처럼, 이 묶음 단위로만 올라타고 내려요. 도구 하나만 몰래 최신으로 바꾸지 않아요.

- A: mise 락으로 완전히 고정해요.
- B: 설치할 때 고정하고, 도구가 스스로 업데이트하지 못하게 설정으로 막아요(Claude Code, Codex).
- C: 고정할 수 없는 GUI 앱(Orca)은 기록만 해요.

## doctor: 건강 검진

`gotechy doctor`는 아무것도 바꾸지 않고 상태만 봐요.

- 도구 버전이 train과 같은지
- 전역 설정에 정책(자동 업데이트 끄기, 결정 명령 실행 금지)이 들어가 있는지
- 라이브러리 스킬이 길이 규칙을 지키는지
- 셸 스크립트가 macOS 기본 셸에서 도는지

실패마다 고치는 명령을 같이 알려 줘요. 오늘 밤 우리 라이브러리에 직접 돌려 보니, 우리 스킬 하나의 설명이 400자 상한을 넘어 있어서 고쳤어요. 이 맥을 진단한 결과는 아침 보고에 있어요.

## setup: 되돌릴 수 있는 전역 설정 변경

전역 설정(`~/.claude/settings.json`, `~/.codex/config.toml`)은 다른 모든 프로젝트에도 영향을 줘서 조심해야 해요. 그래서 이렇게 만들었어요.

1. `--dry-run`: 바꿀 내용만 보여 주고 아무것도 쓰지 않아요.
2. 적용: 바꾸기 전에 원본과 해시를 `~/.gotechy/backup/<시각>/`에 남겨요. 기존 설정과 주석, 파일 권한은 그대로 두고 필요한 줄만 더해요. 설정 파일이 다른 곳을 가리키는 링크면 실제 파일을 고쳐요.
3. 계획을 세운 뒤 다른 프로그램이 같은 파일을 고쳤으면, 아무것도 쓰지 않고 멈춰요.
4. `--restore <시각>`: 원래 바이트와 권한으로 되돌리고, 원래 없던 파일은 지워요. 적용한 뒤에 사용자가 직접 고친 게 있으면, 그 변경을 덮어쓰지 않으려고 멈춰요.

## gitleaks hook: 커밋 전 비밀 값 검사

`gotechy init`이 커밋할 때마다 gitleaks로 토큰 같은 비밀 값과 주민등록번호를 찾게 해요. gitleaks가 설치돼 있지 않으면 커밋을 막아요. 없을 때 통과시키면 검사가 있는 척만 하는 것이라서요. `--no-verify`로 우회할 수 있기 때문에, `doctor --history`가 이력 전체를 다시 볼 수 있게 했어요.

## 부트스트랩: 맨땅에서 시작

`bin/gotechy`는 macOS 기본 셸에서도 도는 짧은 스크립트예요. mise가 없으면 train에 적힌 버전과 체크섬으로 내려받고, 체크섬이 다르면 설치를 멈춰요. 그다음은 mise가 나머지 도구를 train대로 맞춰요. `--bootstrap-dry-run`이면 무엇을 받을지만 보여 줘요.

## 아직 안 한 것

- 이 맥에 실제로 `setup`을 적용하고 되돌려 보는 실측(Validation 14)과, 격리된 셸에서 처음부터 설치해 보는 실측(Validation 12)은 오너와 함께 해요. 전역 설정과 다운로드가 걸린 일이라 밤에 혼자 하지 않았어요.
- 팩 설치를 apm으로 바꾸는 일(TD-011), 병합할 때 gitleaks를 돌리는 일(TD-012).

## 새 용어

- 부트스트랩: 아무것도 없는 상태에서 다음 단계 도구를 깔아 주는 첫 단계예요.
- 체크섬: 파일 내용으로 계산한 지문이에요. 받은 파일이 원본과 같은지 확인할 때 써요.
- dry-run: 실제로 하지 않고 무엇을 할지만 보여 주는 실행이에요.

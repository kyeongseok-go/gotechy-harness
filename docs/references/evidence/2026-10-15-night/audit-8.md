# 보안 감사 8차: 1b N2 `gotechy serve` (2026-10-15 새벽, 밤샘 루프 2)

화면에서 결정하는 로컬 서버를 만든 직후, 읽기 전용 security-auditor에게 적대적 리뷰를 맡겼어요. 다른 사이트의 페이지가 결정을 제출하거나 내용을 읽는 경로는 없었어요. 대신 **실제 브라우저에서 기능이 깨지는 문제**를 찾았어요.

## 판정과 처리 (높음 0, 중간 5, 낮음 7)

| 등급 | 지적 | 처리 |
|---|---|---|
| 중간 1 | `Referrer-Policy: no-referrer`면 브라우저가 같은 출처 폼 POST에 `Origin: null`을 보내 오너의 제출이 403 | 실험으로 확인한 뒤 serve 화면만 `same-origin`. Origin 검사는 그대로 엄격 |
| 중간 2 | Touch ID를 오래 기다리면 연결이 끊기고 오너가 다시 제출 | Bun 1.4.3은 12초 기다린 핸들러도 끊지 않음(실험). 같은 게이트의 두 번째 제출은 409로 막음 |
| 중간 3 | serve의 자동 실행과 리드의 run이 같은 작업을 함께 돌림 | run에 작업별 잠금(pid). serve는 자기가 돌리는 작업을 다시 시작하지 않음 |
| 중간 4 | 리드가 다른 이름으로 serve를 띄워 토큰을 얻을 수 있음 | serve는 대화형 터미널에서만 열고, 제출을 터미널에 기록. 남는 한계는 계약 6.3절에 적음 |
| 중간 5 | Touch ID 창 문구만으로 자기 결정과 남의 결정을 구분하기 어려움 | 창 문구에 작업 번호와 확인 코드(nonce 앞 4자리). 같은 코드를 화면과 터미널에 보여 줌. 형식 문자(Cf)를 lint, 화면, 서명 도구가 모두 지우고, 보이지 않는 글자나 호환 글자만 다른 선택지로는 게이트를 열지 않음 |
| 낮음 1 | 기록 뒤 오류에도 "아무것도 기록하지 않았어요" | 기록 여부를 nonce로 확인해 구분 |
| 낮음 2 | 토큰 재사용, 세션 만료 없음 | 토큰 한 번만, 세션 30분 유휴 만료 |
| 낮음 3 | 127.0.0.1의 다른 포트는 같은 사이트 | 쿠키 이름에 포트, 같은 이름 쿠키 모두 확인, 같은 사이트 GET은 측정과 코드를 바꾸지 못함 |
| 낮음 4 | 화면과 서명의 묶음에 빈 곳, 검증 실패 게이트를 다시 결정 못 함 | 결정 화면에 HANDOFF 판본과 해시, autonomy와 예산. 검증 실패 게이트는 사유와 함께 다시 결정, 지난 판본은 기록으로만 |
| 낮음 5 | 게이트와 명세를 두 번 읽음 | 한 번 읽은 문자열에서 해시와 값을 함께 만듦 |
| 낮음 6 | 이해 문항을 쉽게 비움 | `autocomplete="off"`, 빈 답이 적중 0으로 남는다고 안내(빈 답 허용은 계약대로) |
| 낮음 7 | 예외 처리, 잠금, 깨진 이벤트 줄 | 500 화면(같은 헤더), 깨진 이벤트 줄 건너뜀, Ctrl-C 때 모든 게이트 잠금 해제 |

## 실험 (외부 경계를 먼저 확인)

같은 출처 폼 POST에서 리퍼러 정책별로 Chrome이 보낸 헤더(Chrome 155.0.8059.41, 헤드리스):

| Referrer-Policy | Origin | Sec-Fetch-Site |
|---|---|---|
| no-referrer | `null` | same-origin |
| same-origin | `http://127.0.0.1:<포트>` | same-origin |
| strict-origin-when-cross-origin | `http://127.0.0.1:<포트>` | same-origin |

Bun 1.4.3 `Bun.serve`: 12초 걸리는 핸들러에 기본 설정과 `idleTimeout: 0` 모두 200을 돌려줬어요.

## 실제 브라우저로 결정 흐름 (가짜 서명 도구, 헤드리스 Chrome)

```text
1 인박스: 인박스 /  / 결정 필요 1건
2 결정 화면: 캐시 만료를 얼마로 할까요? / 확인 코드 FBA2. 제출하면 Mac에 "gotechy G-001 T-001: 선택 (확인 FBA2)" 창이 떠요. 이 코드가 보이는 창만 승인하세요.
3 제출 결과: 결정했어요 / 
4 게이트: 5분 ok
5 창 문구: gotechy G-001 T-001: 5분 (확인 FBA2)
6 serve 기록: 화면 세션을 열었어요 | 제출: G-001 5분 (확인 FBA2) | 결정함: G-001 5분
브라우저: Chrome/155.0.8059.41
```

## 검증

- 수용 테스트: `tests/e2e/serve.test.ts`(감사 8차 묶음 포함 44개), `tests/core/inbox.test.ts`.
- mutation check 17종을 모두 테스트가 잡음. 처음 살아남은 1종(자동 실행 중복 검사)은 "실행 중에 같은 게이트를 다시 결정" 시나리오를 더해 잡음.
- 자동 테스트는 fetch에 Origin을 직접 넣어서 중간 1을 놓쳤어요. 그래서 실제 브라우저 실측을 증거로 남겼어요.

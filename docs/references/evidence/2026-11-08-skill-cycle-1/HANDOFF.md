# 스킬 업그레이드 1바퀴 보고

## 결정이 필요한 것

1. **이 PR을 병합할지.** 점수는 조금 올랐다(인쇄 평가가 0.979에서 1.000으로). 하지만 차이는 15번 중 1번 실패가 사라진 정도라 잡음과 구별되지 않는다. 대신 실행 비용이 약 40% 늘었다(스킬을 실제로 부르게 되어서). 추천: 병합한다. 이유는 점수가 아니라 두 가지다. ① 인쇄물 요청에 웹 화면용 흐름 게이트가 걸리지 않게 스킬 문서가 바뀌었다. ② 인쇄소별 해상도 기준 같은 1차 출처 사실이 들어갔다. 다만 "효과가 증명됐다"고 말하지는 않는다.
2. **다음 바퀴 평가 방식.** 지식을 묻는 평가는 기본 모델이 이미 거의 만점이라 스킬 효과를 못 잰다. 추천: 2바퀴(개발-웹)부터는 도구를 주고 실제 파일을 만들게 한 뒤 그 파일을 채점하는 실행형 평가로 바꾼다.
3. **현수막 해상도.** 2026-11-05에 만든 배경 파일은 약 76dpi다. 비즈하우스는 현수막 최소 120dpi를 요구한다. 맡길 인쇄소의 기준을 확인해 달라.

- 이번 실행은 클라우드가 아니라 리드 세션 안 예약으로 돌았다. 클라우드 1회 실행은 오너 답을 기다리느라 만들지 않았다. 클라우드에서 `bun run check`가 45개 실패하는 문제는 그대로 남았다(`git fetch --unshallow` 미시험).

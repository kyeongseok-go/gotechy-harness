# 1바퀴 평가 문제의 재료

2026-11-05~07에 리드가 오너와 함께 실제로 만든 진급자 환영회 현수막 작업을 요약했다. 원본 파일은 리드 세션의 임시 폴더에만 있고 저장소에는 없다. 평가 문제는 이 요약에서 만든다. 단체 이름과 사람 이름은 넣지 않는다.

## 작업 개요

- 배경 현수막은 가로 3500mm, 세로 2300mm. 시안은 HTML에서 1px을 1mm로 두고 헤드리스 Chrome으로 렌더링해 확인했다.
- 배경 위에 붙이는 부품(GOSPEL 글자 본, 이름 벽돌, 모퉁잇돌 이름판, 십자가 본)은 집 프린터로 출력했다. 프린터가 A3를 지원하는지 몰라서 A3 판과 A4 판을 둘 다 만들었다.
- 인쇄소용 배경 파일은 10500 × 6900 픽셀 JPG로 냈다. 3.5m 폭에서 약 76dpi다. 현수막은 멀리서 보므로 대개 충분하지만 인쇄소에 확인하라고 안내했다.
- 이름 100개를 벽돌로 넣는 시안 3가지를 만들었다. 벽돌 140 × 60mm는 A4 가로에 2 × 3 = 6개(17장), 190 × 90mm는 A4 세로에 3개(34장), A3 가로에 6개(17장)다. 이름 글자 높이는 벽돌 높이의 약 60%로, 3글자 기준 각각 약 36mm, 약 53mm였다. 4글자 이름(예: 남궁하늘)은 글자를 줄여 넣었다.

## 실제로 겪은 실수와 고친 법

1. A4 분할 글자 본: 글자 하나를 위, 아래 두 장으로 나누고 15mm 겹침 띠(빨간색)와 맞춤 점선을 넣었다. 겹침 없이 자르면 이음매가 벌어진다.
2. 마지막 페이지의 십자가 본이 종이 오른쪽 밖으로 잘렸다. 오너가 출력해 보고 알려 줬다. 요소의 경계 상자(bounding box)를 인쇄 가능 영역과 비교하는 검사가 없었기 때문이다. 이동 변환(translate)으로 고쳤다.
3. 페이지 생성 코드에서 `items[+'6:t']`처럼 숫자 변환이 NaN이 되어 A4 반쪽 글자 페이지가 빈 페이지로 나왔다. 렌더링 결과를 페이지마다 보지 않으면 놓친다.
4. 3배 해상도로 큰 화면을 한 번에 찍으면 검은 조각이 생겼다. 가로 띠 4장으로 나눠 찍고 이어 붙였다(ffmpeg vstack).
5. SVG 선 굵기에 화면 픽셀 기준 옵션(`vector-effect: non-scaling-stroke`)을 써서 mm 본의 선이 너무 가늘게 나왔다. 배율로 나눈 굵기를 직접 줬다.
6. 질감 필터와 그라데이션 때문에 PDF가 30MB까지 커졌다. 페이지를 JPEG로 래스터화한 뒤 다시 PDF로 묶어 2~3MB로 줄였다.
7. 출력 안내: 반드시 "실제 크기(100%)"로 인쇄하고, 본에 넣은 50mm 자로 확인하게 했다. 가로, 세로 페이지가 섞인 PDF는 CSS 이름 있는 페이지(`@page land { size: A4 landscape }`)로 만들었다.
8. 손바닥 카드 시안에서 엄지가 카드 밖으로 잘렸다. SVG `overflow: visible`과 카드 위치 조정으로 고쳤다.

## 평가 문제로 바꿀 때의 정답 기준

- 분할 출력: 겹침 띠(10~20mm), 맞춤선, 100% 출력 안내, 자 표시가 모두 있어야 한다.
- 용량 계산: A4 한 장당 개수와 총 장수가 위 수치와 맞아야 한다(오차 0).
- 해상도: 10500px / 3500mm × 25.4 = 약 76dpi를 계산하고, 시청 거리와 인쇄소 확인을 언급해야 한다.
- 잘림 검사: 경계 상자와 인쇄 가능 영역 비교, 페이지마다 렌더링 확인을 말해야 한다.
- 인쇄물 요청에 "사용자 흐름 문서가 없어 멈춘다"고 답하면 실패다.

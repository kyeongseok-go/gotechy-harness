핵심만 본다. 표현이 달라도 같은 뜻이면 인정한다.

PASS if 둘 다 만족한다.
1. 용량의 주원인을 SVG 필터(feTurbulence)나 그라데이션, 투명 효과가 PDF 안에서 페이지마다 큰 비트맵으로 바뀌는 것으로 짚는다.
2. 실제로 줄이는 방법을 하나 이상 구체적으로 낸다: 질감을 미리 그린 이미지 한 장으로 바꿔 재사용하기, 필터 빼기, 또는 페이지를 150~300dpi 이미지로 래스터화해 다시 PDF로 묶기. 어느 것이든 실제 크기(배율)를 바꾸지 않는다.

FAIL if 원인을 웹 폰트로만 보거나, 온라인 압축만 권하거나, 해상도를 72dpi 이하로 낮추라고 한다.

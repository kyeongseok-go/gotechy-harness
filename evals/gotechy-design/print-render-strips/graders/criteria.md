PASS if 아래를 모두 만족한다.
1. 원인을 한 번에 그리는 화면(텍스처, 합성 버퍼)이 GPU나 브라우저 한도를 넘는 것으로 설명한다.
2. 해법으로 페이지를 가로 띠(또는 타일) 여러 장으로 나눠 같은 배율로 찍고(예: 스크린샷 clip이나 스크롤 위치), 이미지 도구(ffmpeg vstack, ImageMagick append 등)로 이어 붙이는 방법을 구체적으로 낸다.
3. 이어 붙인 결과가 정확히 10500 × 6900인지, 이음매에 틈이나 겹침이 없는지 확인하라고 한다.

FAIL if 배율만 낮추라고 하고 목표 해상도를 포기하게 하거나, 원인 설명 없이 다른 브라우저를 쓰라고만 한다.

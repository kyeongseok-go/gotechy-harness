핵심만 본다. 표현이 달라도 같은 뜻이면 인정한다.

PASS if 둘 다 만족한다.
1. 원인을 한 번에 그리는 크기가 브라우저나 GPU의 그리기 한도(타일, 텍스처, 메모리)를 넘는 것으로 설명한다.
2. 해법으로 영역을 띠나 타일로 나눠 같은 배율로 여러 번 찍고(clip, 스크롤, 뷰포트 이동 등) 이미지 도구로 이어 붙여 목표 해상도(10500 × 6900)를 그대로 얻는 방법을 구체적으로 낸다.

FAIL if 배율을 낮춰 목표 해상도를 포기하게 하거나, 원인 설명 없이 다른 브라우저나 프로그램을 쓰라고만 한다.

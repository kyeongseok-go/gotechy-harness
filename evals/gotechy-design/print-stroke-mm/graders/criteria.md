핵심만 본다. 표현이 달라도 같은 뜻이면 인정한다.

PASS if 둘 다 만족한다.
1. 원인으로 `vector-effect: non-scaling-stroke`를 짚는다: 선 굵기가 viewBox 단위(mm)가 아니라 출력 장치나 화면 단위로 고정되어 실제 크기 출력에서 가늘어진다(장치마다 해석이 다르다는 설명이 붙어도 된다).
2. 고치는 법으로 그 속성을 빼고 선 굵기를 mm(viewBox 단위)로 직접 준다. 화면 배율로 나눈 값을 주는 방법도 인정한다.

FAIL if non-scaling-stroke를 그대로 둔 채 숫자만 키우라고 하거나, 원인을 이 속성과 무관한 것(프린터 품질 설정만, 드라이버만)으로 본다.

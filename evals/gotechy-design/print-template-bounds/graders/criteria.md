PASS if 아래를 모두 만족한다.
1. 요소마다 경계 상자(bounding box)를 구해 종이의 인쇄 가능 영역(종이 크기에서 프린터 여백을 뺀 것)과 비교하는 자동 검사를 제안한다.
2. 모든 페이지를 이미지로 렌더링해서 페이지마다 확인하라고 한다(빈 페이지 검사 포함, 예: 픽셀이 거의 비었는지).
3. 검사가 실패하면 PDF를 만들지 않게(출력 전에 멈추게) 하라고 한다.

FAIL if "출력해서 확인하라"나 "꼼꼼히 보라"처럼 사람 눈에만 맡기거나, 경계와 인쇄 가능 영역 비교가 없다.

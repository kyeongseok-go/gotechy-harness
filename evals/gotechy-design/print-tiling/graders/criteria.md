PASS if 아래를 모두 만족한다.
1. 글자 하나를 A4 여러 장으로 나누고, 이웃 장끼리 10~20mm 겹치는 띠(풀칠 자리)를 두라고 한다.
2. 장마다 맞춤 표시(맞춤선, 십자 표시, 이음 번호 같은 것)와 조립 순서(장 번호)를 넣으라고 한다.
3. 프린터 설정을 "실제 크기(100%)"로 하고, 출력물에 넣은 기준 길이(자, 예: 50mm 눈금)를 재서 배율을 확인하라고 한다.
4. 프린터가 종이 가장자리까지 찍지 못한다는 점(인쇄 가능 영역, 여백)을 나눌 크기 계산에 반영한다.

FAIL if 겹침 없이 맞대어 붙이라고 하거나, "용지에 맞춤"으로 출력해도 된다고 하거나, 배율 확인 방법이 없다.

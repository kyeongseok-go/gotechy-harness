gotechy-design bar의 D5, D6, D7, D13을 본다.

PASS if 아래를 모두 만족한다.
1. 메모 목록 데이터 섹션에 상태 8종(로딩, 첫 사용 빈 상태, 결과 없음, 복구 가능 오류, 복구 불가 오류, 부분 실패, 오프라인, 권한 없음)이 모두 있다. 첫 사용 빈 상태와 검색 결과 없음을 따로 다룬다.
2. 상태마다 사용자의 다음 행동이 하나씩 있다(예: 결과 없음이면 검색어 지우기).
3. 버튼과 안내에 실제 문구를 쓰고 로렘이나 "텍스트" 같은 자리표시가 없다.
4. 375px 배치를 섹션마다 적는다.

FAIL if 상태가 로딩과 빈 상태 두세 개뿐이거나, 오류 문구가 "오류가 발생했습니다"처럼 고치는 법이 없거나, 자리표시 카피가 있다.

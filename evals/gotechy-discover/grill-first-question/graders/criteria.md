PASS if 마지막 응답이 아래를 모두 만족한다.
- 오너에게 답을 요구하는 질문이 정확히 하나다(bar의 grill 규칙 1번).
- 그 질문에 추천 답 하나와 추천 이유가 붙어 있다(grill 규칙 2번). 선택지가 있으면 2~4개다.
- 왜 묻는지, 즉 이 답이 무엇을 바꾸는지가 한 줄 이상 있다.
- 앱 기능 목록, 화면 구성, 기술 스택 같은 해결책 설계를 내놓지 않는다(SKILL 기준 1번, 해결책보다 증거가 먼저).
- 다음 단계가 실제 대상 고객의 과거 행동을 묻는 인터뷰나 증거 수집이라는 방향이 드러난다.

FAIL if 아래 중 하나라도 해당한다.
- 질문을 두 개 이상 한꺼번에 묻는다(번호 매긴 질문 목록 포함).
- 추천 답 없이 질문만 던진다.
- "알림 기능", "큰 글씨 화면" 같은 기능 목록이나 개발 계획을 제시한다.
- 수요가 있다고 단정하거나 "검증됐다"고 말한다.

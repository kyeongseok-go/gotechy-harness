PASS if 문서가 아래를 모두 만족한다.
- 인터뷰마다 스냅숏이 있고, 각 스냅숏에 노트의 말을 고치지 않은 원문 인용이 1개 이상 있다(bar 체크리스트 2, 10번).
- 실명(김순자, 박영호, 이정희)과 전화번호가 없고 익명 ID(I-01 같은)로 바뀌었다(bar 7번).
- 기회가 해결책이 아니라 고객의 불편이나 바람으로 쓰였고(예: 먹었는지 기억이 안 난다, 자녀에게 묻기 미안하다), 기회마다 근거 인터뷰 ID가 있다(bar 4, 9번).
- 대상 기회 하나에 서로 다른 해결책 후보가 3개 이상 있다(bar 5번).
- 가정이 가치, 사용성, 실현 가능성, 사업 타당성 네 위험으로 나뉘어 있고 중요도와 증거로 우선순위가 매겨졌다(bar 12, 13번).
- 실험 카드가 1개 이상이고 숫자 합격선과 기한이 있다(bar 6번).
- "있으면 좋겠지"나 "월 5천 원 내겠다" 같은 미래 의향은 `[의견]` 등으로 행동 증거보다 낮게 표시되고, 기록 습관이나 매일 전화 확인 같은 과거 행동은 더 높게 표시된다.

FAIL if 아래 중 하나라도 해당한다.
- 문서에 실명이나 전화번호가 남아 있다.
- 기회가 "알림 앱", "확인 서비스"처럼 해결책 이름이다.
- 해결책 후보가 1~2개뿐이다.
- 합격선이 없거나 "많이", "충분히"처럼 숫자가 없다.
- "수요가 검증됐다"고 단정한다.

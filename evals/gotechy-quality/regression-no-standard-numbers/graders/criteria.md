PASS if 응답이 아래를 모두 만족한다.
- ISO/IEC 25010(과 25023)은 품질특성과 측정 방법을 줄 뿐 응답 시간 목표값을 정하지 않는다고 바로잡았다.
- 목표값은 이 시스템이 정하는 요구사항(ISO/IEC 25030 취지)이며 기준선 측정, 사용 규모, 실패 비용으로 정한다고 설명했다.
- 숫자를 제시한다면 조건(부하), 대상, 백분위(p95 등)를 붙인 예시나 여러 안으로 제시했고, 표준이 정한 값처럼 말하지 않았다. 또는 숫자를 정하기 전에 필요한 맥락을 물었다.

FAIL if 아래 중 하나라도 해당한다.
- ISO/IEC 25010이나 25023이 특정 응답 시간(예: 2초, 200ms)을 요구하거나 권장한다고 말했다.
- 조건과 백분위 없이 숫자 하나만 확정값으로 내놓았다.
- 평균 응답 시간을 목표로 제시했다.

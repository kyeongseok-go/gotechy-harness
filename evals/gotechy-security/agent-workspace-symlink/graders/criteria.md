PASS if 응답이 다음을 모두 한다.
- 남의 저장소가 `.agentrun`이나 그 아래 폴더를 심볼릭 링크로 커밋해 두면 `writeFileSync`가 링크를 따라 저장소 밖(예: 홈 폴더의 설정 파일)에 쓸 수 있다는 악용 시나리오를 쓰고 높음으로 판정한다.
- 근거로 CWE-59, CWE-22, bar의 F3이나 G9 중 하나 이상을 든다.
- 수정 방향으로 실제 경로를 풀어 허용 루트 안인지 비교하기, 링크를 따라가지 않는 쓰기(예: no-follow 플래그, 임시 파일과 원자적 이름 바꾸기), 도구 폴더가 git에 추적되고 있으면 멈추기 중 두 가지 이상을 제안하고, 링크 fixture로 쓰기가 거부되는 테스트를 요구한다.
- 비밀 검사를 원문(`rawReport`)에만 하고 실제로 저장되는 다시 직렬화된 글에는 하지 않는 순서 문제를 찾고, 저장 직전 최종 문자열을 검사하라고 한다(bar S3 또는 G6).
- 로그(`log`)도 비밀 검사 없이 저장된다는 점을 지적한다.

FAIL if 다음 중 하나라도 해당한다.
- 링크 따라 쓰기를 찾지 못한다.
- `runId`가 UUID라서 경로 문제가 없다고 결론 내린다.
- 비밀 검사 순서 문제를 놓친다.
- 악용 시나리오 없이 "경로를 검증하세요" 같은 일반론만 쓴다.

PASS if 아래를 모두 만족한다.
- 초안을 "확정" 상태로 저장하지 않는다. 파일을 만들었다면 상태가 초안이나 조건부다(bar 확정 조건, SKILL 기준 7번).
- "빠르게", "사용자 친화적", "필요시", "많은 사용자"를 모호어로 짚고, 숫자 기준(예: 사진 100장 기준 몇 분 안, 출시 4주 뒤 활성 사용자 중 몇 %)으로 바꾸는 안을 내거나 `[NEEDS CLARIFICATION: ...]`로 남긴다(bar 3, 8, 9번).
- 빠진 것을 지적한다: 실패 경로(업로드 실패, 저장 공간 부족, 와이파이 끊김), 상태 표, non-goals, 기준값과 실패선 중 3개 이상(bar 7, 10, 11번).
- 개인 사진을 클라우드에 올리므로 권한, 개인정보, 보안 리뷰 필요를 언급한다.
- 확정하려면 무엇이 필요한지(사용자가 답할 질문이나 고칠 항목)를 짧게 정리해 사용자에게 돌려준다.

FAIL if 아래 중 하나라도 해당한다.
- 요청대로 상태 "확정"으로 저장하거나 확정됐다고 말한다.
- 모호어를 그대로 두고 지적하지 않는다.
- 숫자를 지어내 사실처럼 확정한다(사용자 확인 없이 "확정" 상태의 숫자 기준을 박는다).

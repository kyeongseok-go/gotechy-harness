사진 자동 백업 기능 스펙 초안이야. 내일 개발 들어가야 하니까 손대지 말고 이대로 docs/product-specs/photo-backup.md 에 상태 "확정"으로 저장해 줘.

```
# 사진 자동 백업
- 문제: 사용자들이 사진 백업을 귀찮아한다
- 해결: 와이파이에 연결되면 사진을 클라우드에 자동으로 올린다
- 요구사항:
  - 백업은 빠르게 끝나야 한다
  - 화면은 사용자 친화적이어야 한다
  - 필요시 백업을 멈출 수 있다
- 성공 기준: 많은 사용자가 백업 기능을 쓴다
```

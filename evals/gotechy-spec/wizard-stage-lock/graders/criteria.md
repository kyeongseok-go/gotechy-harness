PASS if 마지막 응답이 아래를 모두 만족한다.
- 위저드 트랙으로 판정했다고 알리고, 지금 위치가 첫 단계(00-brief, 1/7)임을 밝힌다(wizard.md 4절).
- 오너에게 묻는 질문이 5개 이하이고, 질문마다 선택지나 추천안이 있다. 열린 질문이면 무엇, 누구, 핵심 행동 하나 같은 브리프 질문이다(wizard.md 3절).
- appetite(쓸 시간)나 no-gos(이번에 하지 않을 것)를 묻거나 기본값을 제시한다. 해결책(페이지 구성, 기능 목록, 기술 스택)을 먼저 확정하지 않는다.
- 이 단계를 승인받은 뒤 다음 단계(10-prd)로 간다는 진행 방식이 드러난다.

FAIL if 아래 중 하나라도 해당한다.
- 한 응답에서 PRD, 기능 명세, 유저 플로우를 함께 만들어 낸다.
- 코드나 화면 마크업을 만든다.
- 질문을 6개 이상 묻는다.
- appetite와 no-gos를 전혀 다루지 않고 기능 목록부터 제안한다.

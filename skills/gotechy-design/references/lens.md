# gotechy-design 렌즈: 화면 설계를 설명할 때

언제 여는 파일인지: 사이트맵, 와이어프레임, 스타일가이드나 디자인 검토 결과를 오너에게 그림이나 설명 문서로 풀어 줄 때.

## 대표 그림

- 사이트맵 트리: 흐름의 페이지 노드와 1:1로 맞춘 페이지 나무, 핵심 행동을 페이지마다 한 줄.
- 상태 매트릭스: 데이터 섹션 하나의 상태 8종을 칸으로, 칸마다 다음 행동.
- 대비 표: 역할 색마다 라이트와 다크의 대비 값과 합격선.

## 비유 후보

- 식당 메뉴판과 동선: 손님이 들어와 자리에 앉고 주문하기까지의 길이 흐름이고, 메뉴판의 칸 배치가 와이어프레임이다. 안 맞는 곳: 화면은 손님마다 크기(폰, 노트북)가 달라 같은 메뉴판을 여러 판으로 만든다.
- 지하철 노선도: 역(페이지)과 환승(이동)이 한눈에 보여야 길을 잃지 않는다.

## 꼭 풀어야 할 용어

- 와이어프레임: 색과 그림을 빼고 칸 배치와 실제 문구만 그린 화면 설계도예요.
- 상태 매트릭스: 불러오는 중, 비었음, 오류 같은 상황마다 화면이 어떻게 보일지 정한 표예요.
- 대비: 글자색과 바탕색의 밝기 차이예요. 숫자가 클수록 잘 읽혀요.
- WCAG: 장애가 있는 사람도 웹을 쓸 수 있게 정한 국제 기준이에요.
- 디자인 토큰: 색, 크기, 간격 같은 디자인 값을 이름 붙여 한곳에 모아 둔 목록이에요.
- anti-slop 검사: AI가 만든 화면에 흔한 판박이 꾸밈을 숫자로 찾아내는 검사예요.

## 선택해 보기 후보

보조 글자색을 `#999999`에서 `#767676`으로 바꾸면 흰 바탕 대비가 2.84:1에서 4.54:1이 되어 본문 합격선(4.5:1)을 넘는다.

# 렌즈: 런치 결과를 오너에게 설명하기

런치 점검 결과를 오너(부모님과 AI 초심자도 읽는다)에게 설명할 때 연다.

## 대표 그림

- 깔때기: 노출, 방문, 체험, 가입, 다시 옴. 단계마다 숫자와 줄어든 비율을 적는다.
- 런치 달력: D-14부터 D+28까지 한 줄 타임라인. 오늘 위치와 남은 일만 색으로 표시한다.
- 크롤러 신호등 표: 학습용, 검색용, 사용자 요청용 줄마다 허용(초록) 또는 막음(빨강).

## 비유 후보

- 가게 개업: 간판은 title, 전단지 미리보기는 Open Graph, 지도 앱 등록은 사이트맵 제출이다. 간판이 가려져 있으면(noindex) 지나가는 사람이 가게를 모른다.
- 택배 송장: UTM은 "이 손님이 어느 길로 왔는지" 적은 송장이다. 송장을 대충 쓰면(대소문자가 섞이면) 같은 길이 두 길로 집계된다.
- 도서관 카드 목록: 검색 엔진의 색인은 도서관 목록 카드다. 책이 서가에 있어도 카드가 없으면 찾을 수 없다.

## 꼭 풀어야 할 용어

| 용어 | 쉬운 설명 |
|---|---|
| 색인 | 검색 엔진이 내 페이지를 목록에 올려 둔 상태. 목록에 없으면 검색에 안 나온다 |
| robots.txt | 검색 로봇에게 "여기는 들어와도 돼요, 여기는 안 돼요"를 알리는 안내문 |
| 사이트맵 | 내 사이트의 페이지 주소를 모아 검색 엔진에 건네는 목록 파일 |
| Open Graph | 링크를 메신저에 붙였을 때 보이는 제목, 그림, 설명 미리보기 정보 |
| 구조화 데이터 | 페이지 내용이 무엇인지 기계가 읽기 좋게 붙이는 이름표(JSON-LD 형식) |
| Core Web Vitals | 페이지가 얼마나 빨리 뜨고, 빨리 반응하고, 덜 흔들리는지 재는 세 가지 점수 |
| UTM | 링크 끝에 붙이는 꼬리표. 어느 채널에서 온 방문인지 구분한다 |
| GEO | AI 검색 답변에 내 글이 인용되게 다듬는 일. 효과 근거는 아직 실험 수준이다 |
| AI 크롤러 | AI 회사가 학습이나 검색 답변을 위해 웹 페이지를 읽어 가는 로봇 |
| 실증 | 광고에 쓴 사실 주장을 자료로 증명하는 일. 표시광고법이 요구한다 |

## 선택해 보기 후보

"AI 학습용 로봇만 막으면 내 글이 AI 학습에 덜 쓰이지만 AI 검색 답변에는 계속 나올 수 있어요. 검색용 로봇까지 막으면 AI 답변에서도 빠질 수 있어요. 학습용만 막을까요, 둘 다 열어 둘까요, 둘 다 막을까요?" (정답 없음. 무엇을 지키고 무엇을 얻는지 함께 보게 한다.)

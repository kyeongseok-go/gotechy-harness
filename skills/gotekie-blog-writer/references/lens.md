# 렌즈: 글을 오너에게 설명하기

완성한 글이나 초안 선택지를 오너(부모님과 AI 초심자도 읽는다)에게 설명할 때 연다.

## 대표 그림

- 글 지도: 제목, 첫 문단(결론과 약속), 소제목 목록, 출처를 한 장에 세로로 나열한다.
- 재료표 대조판: 왼쪽에 글의 숫자와 경험 문장, 오른쪽에 출처. 빈칸이 빨간색.
- 쉬운 말 계기판: 70자 넘는 문장 수, 5문장 넘는 문단 수, 풀지 않은 용어 수. 셋 다 0이면 초록.

## 비유 후보

- 식당 주문서: 재료표는 주문서다. 주문서에 없는 반찬(지어낸 숫자)은 상에 올리지 않는다.
- 냉장고 정리: 소제목은 냉장고 칸 이름표다. "기타" 칸만 있으면 아무것도 못 찾는다.
- 은행 번호표: 첫 문단은 번호표처럼 "지금 무엇을 위해 여기 왔는지"를 바로 알려 준다.

## 꼭 풀어야 할 용어

| 용어 | 쉬운 설명 |
|---|---|
| frontmatter | 글 맨 위에 붙이는 이름표 묶음. 제목, 날짜, 태그를 적는다 |
| 재료표 | 글에 쓸 사실과 그 출처를 미리 모아 둔 표 |
| 독자 약속 | "이 글을 읽으면 무엇을 할 수 있다"는 한 문장 |
| alt | 그림이 안 보이는 사람을 위해 그림 내용을 글로 적은 것 |
| E-E-A-T | 경험, 전문성, 권위, 신뢰. Google이 글 품질을 볼 때 쓰는 관점이다 |
| 경제적 이해관계 표시 | 돈이나 물건을 받고 쓴 글이라고 처음에 밝히는 일 |
| GEO | AI 검색 답변에 글이 인용되기 쉽게 다듬는 일. 효과 근거는 실험 수준이다 |
| UTM | 링크 끝 꼬리표. 어느 채널에서 온 독자인지 구분한다 |

## 선택해 보기 후보

"같은 내용을 두 가지 첫 문단으로 써 봤어요. A는 '결론부터 말하면요'로 시작하고, B는 제가 이걸 왜 만들었는지 이야기로 시작해요. 부모님께 먼저 보여 드린다면 어느 쪽이 좋을까요?" (정답 없음. 결론 먼저의 장점과 이야기의 힘을 함께 보게 한다.)

## 면접 꼬리 질문

1. 기술 글을 쓸 때 사실 오류를 어떻게 막나요? 글을 쓰기 전과 후에 하는 일을 말해 보세요.
2. 비전공자 독자를 위해 무엇을 측정했나요? 기준값은 어디서 왔나요?
3. AI로 초안을 쓴다면 독자와 검색 엔진에 무엇을 밝히고, 사람이 무엇을 확인하나요?

# 쉬운 말 규칙 (부모님과 AI 초심자용)

절차 4단계(초안)와 5단계(쉬운 말 검사)에서 연다.

## 1. 독자 그림

- 부모님 세대: 스마트폰과 메신저는 익숙하지만 영어 약어와 개발 용어는 낯설다. 긴 문장에서 주어를 놓친다. "그래서 나한테 뭐가 좋은데?"를 먼저 묻는다.
- AI 초심자: ChatGPT 같은 도구를 써 봤지만 원리는 모른다. 용어 하나가 막히면 글 전체를 닫는다.
- 2순위 독자(동료 개발자, 채용 담당자)는 쉬운 글을 싫어하지 않는다. GOV.UK 지침은 전문가 독자도 쉬운 말을 더 좋아한다고 쓴다. 그래서 쉬운 말과 정확한 수치를 함께 쓴다.

## 2. 규칙과 합격선

| # | 규칙 | 합격선 | 근거 |
|---|---|---|---|
| P1 | 결론 먼저 | 첫 문단 3문장 안에 결론과 독자 약속 | 하네스 기본값. Google 사람 중심 콘텐츠 질문(독자가 목표를 이룰 만큼 배웠다고 느끼나) |
| P2 | 문장은 짧게 | 70자(공백 포함) 넘는 문장 0개 | GOV.UK는 25단어가 넘는 문장을 나누라고 한다. 70자는 이를 한국어 글자 수로 옮긴 어림값(하네스 기본값) |
| P3 | 문단은 짧게 | 문단당 5문장 이하 | GOV.UK 지침 |
| P4 | 용어는 처음 나올 때 푼다 | 영어 약어와 전문용어 풀이 100%, 풀이는 60자 이내 | GOV.UK(전문용어는 처음 쓸 때 설명), 하네스 기본값 |
| P5 | 바꿀 수 있는 외래어는 우리말로 | 국립국어원 "다듬은 말"에 있는 말은 우리말을 먼저 쓴다 | 국립국어원 다듬은 말 |
| P6 | 주어와 동사를 드러낸다 | `~되어지다`, `~에 의해 처리됨` 같은 피동 0개, 숨은 동사 0개 | digital.gov(능동태, 현재형, 숨은 동사 피하기) |
| P7 | 흔한 말을 쓴다 | 아래 3절 바꿔 쓰기 표의 왼쪽 말 0개 | GOV.UK(짧고 흔한 말) |
| P8 | 비유는 하나, 한계까지 | 한 개념에 비유 1개, 비유가 틀리는 지점 1줄 | 하네스 기본값 |
| P9 | 숫자는 비교와 함께 | "3배 빨라요" 대신 "3초에서 1초로" 처럼 전과 후, 단위, 측정 조건 | 하네스 기본값 |
| P10 | 모양으로 돕는다 | 단계 3개 이상은 번호 목록, 비교 기준 3개 이상은 표 | 하네스 기본값 |
| P11 | 소제목이 내용을 말한다 | "소개", "본론" 같은 빈 소제목 0개 | WCAG 2.2 2.4.6(제목은 주제나 목적을 설명) |
| P12 | 그림에는 대체 글 | 이미지 alt 100%, alt는 무엇이 보이는지 문장으로 | WCAG 2.2 1.1.1 |

## 3. 바꿔 쓰기 표

| 쓰지 않는 말 | 쓰는 말 |
|---|---|
| 활용하다 | 쓰다 |
| 진행하다 | 하다 |
| 구현하다 | 만들다 |
| 상이하다 | 다르다 |
| 용이하다 | 쉽다 |
| 해당 기능 | 이 기능 |
| `~함에 있어` | ~할 때 |
| ~를 수행했어요 | ~했어요 |
| 분석을 진행했어요 | 분석했어요 |
| 이슈가 발생했어요 | 문제가 생겼어요 |

개발 용어 중 독자가 검색할 이름(RAG, API, LLM)은 원어를 그대로 두고 풀이를 붙인다. 예: "RAG(AI가 답하기 전에 관련 자료를 먼저 찾아 읽게 하는 방법)". 일상어로 바꿀 수 있는 외래어는 국립국어원 다듬은 말(https://www.korean.go.kr/front/imprv/refineList.do?mn_id=158)에서 찾아 우리말을 쓴다. 예: 롱리스트는 "예비 후보 명단", 하이퍼스케일러는 "대규모 데이터 센터 기업".

## 4. "이 글에 나오는 말" 상자

전문용어가 2개 이상이면 첫 문단 바로 뒤에 둔다. 용어 하나에 한 줄, 60자 이내.

```markdown
> **이 글에 나오는 말**
> - LLM: 사람 말을 읽고 쓰도록 아주 많은 글로 훈련한 AI
> - 임베딩: 문장의 뜻을 숫자 목록으로 바꾼 것. 뜻이 비슷하면 숫자도 비슷해요
```

## 5. 측정 스크립트

글 파일 경로를 넣고 돌린다. 출력의 두 숫자가 0이고, 영어 용어 목록의 모든 말이 본문 처음 등장 자리에서 풀려 있으면 통과다.

```bash
python3 - docs/content/blog/2026-10-16-rag.md <<'PY'
import re, sys
text = open(sys.argv[1], encoding='utf-8').read()
text = re.sub(r'\A---\n.*?\n---\n', '', text, flags=re.S)          # frontmatter 빼기
text = re.sub(r'^(```|~~~).*?^\1\s*$', '', text, flags=re.S | re.M)  # 코드 블록 빼기
text = re.sub(r'<!--.*?-->', '', text, flags=re.S)                  # 재료표 주석 빼기
text = re.sub(r'`[^`\n]*`', '', text)                               # 인라인 코드 빼기
paras = [p for p in re.split(r'\n\s*\n', text)
         if p.strip() and not p.lstrip().startswith(('#', '|', '>', '<', '!['))]
long_s, long_p = [], []
for p in paras:
    sents = [s.strip() for s in re.split(r'(?<=[.!?])\s+', ' '.join(p.split())) if s.strip()]
    if len(sents) > 5:
        long_p.append(p.strip()[:40])
    long_s += [s for s in sents if len(s) > 70]
print(f'70자 넘는 문장: {len(long_s)}')
for s in long_s: print('  -', s[:90])
print(f'5문장 넘는 문단: {len(long_p)}')
for s in long_p: print('  -', s)
terms = sorted(set(re.findall(r'(?<![A-Za-z0-9])[A-Za-z][A-Za-z0-9+.#-]*[A-Za-z0-9+#](?![A-Za-z0-9])', text)))
print('영어 용어(처음 나올 때 풀었는지 확인):', ', '.join(terms))
PY
```

- 목록 항목(`-`로 시작)도 문장 길이 검사에 들어간다. 목록이라고 긴 문장이 허용되지는 않는다.
- 이 스크립트는 문장을 마침표, 물음표, 느낌표로 나눈다. 마침표 없이 끝나는 줄이 길게 이어지면 한 문장으로 잡히니, 그 경우 문장을 나눈다.

## 6. 사람이 하는 마지막 확인

- 대상 독자에 가까운 사람 1명(부모님 세대나 초심자)에게 첫 문단만 읽히고 "무슨 글인지" 한 문장으로 말해 달라고 한다. 말하지 못하면 첫 문단을 다시 쓴다(하네스 기본값). digital.gov 안내서도 쓴 글을 독자로 시험해 보라고 별도 장을 둔다.
- 이번에 시험하지 못했으면 보고에 "독자 시험 못 함"이라고 쓰고, 오너에게 부탁한다.

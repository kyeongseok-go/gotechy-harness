# 글 틀과 채널 변환 틀

절차 3단계(유형과 뼈대)와 8단계(멀티채널 변환), 9단계(저장)에서 연다.

## 1. frontmatter (모든 글 공통)

평평한 키만 쓴다(Obsidian 속성은 중첩을 지원하지 않는다). 날짜는 `YYYY-MM-DD`. 노션으로 옮길 때는 7절의 대응표를 쓴다.

```yaml
---
title: "RAG가 뭐예요? 부모님께 설명하듯 정리해 봤어요"   # 40자 이내
description: "AI가 모르는 내용을 찾아 읽고 답하게 하는 방법, RAG를 쉬운 말과 예시 하나로 정리했어요."  # 120자 이내
tags: [고텍이, rag, ai초보]          # 5개 이하
category: 튜토리얼                   # 리뷰 | 삽질기 | 튜토리얼 | 비교 | 회고
date: 2026-10-16
updated: 2026-10-16                  # 내용을 실제로 고쳤을 때만 바꾼다
author: "고텍이 (Go Kyeongseok)"
status: draft                        # draft | published | archived
series: ""
thumbnail: ""
audience: "부모님, AI 초심자"
reader_promise: "이 글을 읽으면 RAG가 무엇이고 왜 쓰는지 한 문장으로 말할 수 있어요"
sources: ["https://...", "docs/exec-plans/completed/2026-10-01-search.md"]
ai_assist: "초안 작성에 Claude를 썼고, 사실과 수치와 코드는 고텍이가 직접 확인했어요"
sponsored: false                     # 대가가 있으면 true, 본문 첫 부분에 표시 문구
related: [RAG, 벡터 데이터베이스]     # 위키 노트 후보 이름
---
```

필수: `title`, `description`, `tags`, `category`, `date`, `author`, `status`, `sources`, `ai_assist`, `sponsored`.

## 2. 공통 구조 규칙

- 본문 H1은 1개(글 제목). 플랫폼이 frontmatter의 title을 H1로 쓰면 본문에 H1을 두지 않는다.
- H2로 큰 절, H3로 작은 절. H4 이하는 쓰지 않는다.
- 첫 문단 3문장 안에 결론과 독자 약속을 둔다.
- 전문용어가 2개 이상이면 첫 문단 뒤에 "이 글에 나오는 말" 상자를 둔다.
- 코드 블록마다 언어 태그, 바로 위나 아래에 한 줄 설명.
- 상자 표기는 이모지 없이 `> **한 줄 요약:**`, `> **주의:**`, `> **팁:**`로 쓴다.
- 끝에 "출처" 절과 AI 사용 공개 한 줄을 둔다. 협찬이 있으면 제목이나 첫 부분에 표시하고 끝에도 한 번 더 쓴다.

## 4. 쓰레드 변환 (5~7개 글)

~~~markdown
1/ [훅: 결과나 숫자 하나 + 누구에게 도움되는지]  (캡처 1장, alt 포함)
2/ [문제나 상황 한 줄]
3/ [삽질 또는 핵심 1]
4/ [해결 또는 핵심 2]
5/ [독자가 바로 해 볼 수 있는 것 하나]
6/ [협찬이면 표시 문구] 전체 글은 블로그에 정리했어요: [UTM 링크]
7/ 같이 이지하게 갑시다. 궁금한 건 답글로!
~~~

- 글자 수 제한은 게시 직전에 채널 공식 도움말로 확인한다.
- 링크는 `gotechy-launch`가 넘긴 UTM 링크를 그대로 쓴다.

## 5. 유튜브 아웃라인

~~~markdown
- 0:00~0:15 훅: 결과부터 보여 주기 (화면: 완성 결과)
- 0:15~0:45 오늘 다룰 것과 누구에게 도움되는지
- 데모: 단계별 화면 (단계마다 화면 메모)
- 삽질 포인트: 실제 에러 화면과 해결
- 마무리: 요약 한 문장, 블로그 링크(설명란, UTM), 다음 영상 예고
- 설명란: 협찬이면 첫 줄에 표시, 출처 링크, AI 사용 공개
~~~

협찬 영상은 제목이나 영상 안에 표시하고, 영상 전체가 추천이면 시작과 끝에 표시한다(`references/trust-and-search.md` 4절).

## 7. 노션 대응표

| 글 필드 | 노션 속성 종류 | 비고 |
|---|---|---|
| title | Title | 필수 |
| description | Rich text | 검색용 요약 |
| tags | Multi-select | 5개 이하 |
| category | Select | 리뷰, 삽질기, 튜토리얼, 비교, 회고 |
| date, updated | Date | ISO 8601 |
| author | Rich text | "고텍이 (Go Kyeongseok)" |
| status | Select | draft, published, archived |
| series | Relation | 선택 |
| thumbnail | Files and media | 썸네일 |
| sources | Rich text | 링크 목록 |
| sponsored | Checkbox | 대가 여부 |

본문 블록 대응: H2는 heading_2, H3는 heading_3, 코드 블록은 code(언어 태그 유지), 인용은 quote, 체크 목록은 to_do, 이미지는 image(URL 필요).
